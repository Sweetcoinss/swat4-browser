## KEY GAME SYSTEMS
## ================
### Mission Flow
1. SwatGameInfo (GameInfo) manages mission lifecycle
2. SwatGamePlayerController handles player input and commands
3. SwatPlayer / SwatPawn represents player character
4. SwatOfficer represents SWAT team members (AI)
5. SwatEnemy / SwatSuspect represents hostiles

### Objectives (SwatObjectives/)
- Do_ArrestTargetEnemies, Do_NeutralizeTargetEnemies, etc.
- Do_RescueAllHostages, Do_SecureTargetEvidence, etc.
- DoNot_LetOfficerDie, DoNot_LetHostageDie, etc.

### Scoring (SwatProcedures/)
- Procedure_ArrestSuspects, Procedure_NeutralizeSuspects
- Procedure_NoOfficerInjured, Procedure_NoHostageKilled
- Procedure_CompleteMission

### AI (Tyrion + SwatAICommon)
- Behavior trees (Tyrion framework)
- Officer AI: follow commands, clear rooms, arrest
- Suspect AI: flee, fight, surrender
- Navigation: pathfinding, door handling

### Equipment (SwatEquipment/)
- Weapons: pistols, rifles, shotguns, less-lethal
- Tactical: flashbangs, CS gas, stinger grenades
- Armor: protective gear

## DECOMPILATION METHOD
## ====================
Tool: UELib (Eliot VU) with SWAT4 build profile
Wrapper: DecompileAll.exe (C#) 
- Initializes each package (InitializePackage)
- Writes one .uc per UClass
- Native calls: __NFUN_<n>__ → resolved via native map
- Control flow: structured if/for/while/switch where possible
